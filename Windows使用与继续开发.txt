动漫庭院 Windows 转接包
========================

一、首次启动
1. 安装 Node.js 22.13 或更新版本：https://nodejs.org/
2. 解压整个压缩包，不要只打开压缩包内部的文件。
3. 双击“启动动漫庭院.cmd”。
4. 浏览器会自动打开 http://127.0.0.1:3210/#home
5. 保持黑色命令窗口开启；关闭窗口即可停止应用。

二、继续开发
1. 推荐使用 VS Code 打开整个 anime-garden 文件夹。
2. 页面逻辑：public/app.js
3. 页面样式：public/styles.css
4. 本地服务器：server.mjs
5. 视频、音乐、按钮音效：public/media
6. 在终端运行 npm start 启动，运行 npm test 检查。
7. 修改页面文件后刷新浏览器；修改 server.mjs 后需重启。

三、注意
- 不要直接双击 public/index.html，必须通过启动脚本或 npm start 运行。
- .env 用于个人密钥，不会包含在转接包和 GitHub 中。
- data/personal.json 是本机个人数据，不会包含在转接包和 GitHub 中；首次运行会自动创建。
- 顶部“添加背景音乐”目前只有界面样式，不会真正上传或保存音乐。

# 动漫庭院

本地运行的二次元动漫检索与交流网站。当前版本使用八个动态视频页面背景、暖色庭院面板、漫画贴纸按钮、背景音乐和按钮音效，同时保留完整源码供继续开发。

## 打开

Windows 上安装 Node.js 22.13 或更新版本后，双击 **Start-Anime-Garden.cmd**。脚本会自动打开 **http://127.0.0.1:3210/#home**；保留命令窗口，关闭窗口即可停止应用。英文文件名可避免部分 Windows 解压工具把中文脚本名显示成乱码。

开发时可在项目目录执行 `npm start`，修改 `public/app.js`、`public/styles.css` 或 `server.mjs` 后刷新浏览器查看。没有第三方运行依赖，无需 npm install。执行 `npm test` 可运行全部检查。不要直接双击 `public/index.html`。

## 最新界面功能

- 八个页面分别使用动态视频背景，并保留原有导航和页面结构。
- 全局背景音乐支持播放、暂停和音量调节。
- 顶部“＋”可展开“我的背景音乐”样式面板；当前只预览文件名，真实添加功能尚未启用。
- 按钮使用漫画贴纸风格、动漫菜单互动动画和柔和弹跳音效。
- Windows 超窄屏会把账号入口放入移动导航，避免顶部控件拥挤。

## 目前可用

- 首页六个滚动模块入口；桌面侧栏与移动端菜单。
- 知你所想：AI 候选动漫、理由与追问、持续补充线索、历史、加入追番。未配置 AI 时明确提示，绝不伪造识别。
- 服务工具：平台与资料站分类、搜索、收藏与外链。
- 饭后茶园：云端帖子、分类搜索、编辑删除、评论、点赞/取消、举报。
- 集思广益：简短求助、建议、发帖人采纳/撤销答案、解决状态。
- 追番：周一到周日的个人排期、更新时间、来源、已看集数与编辑移除。第一版为手动排期，不是自动同步的当季番表。
- 观看：官方站跳转；有权使用的 MP4/WebM HTTPS 直链与官方允许的 YouTube 嵌入、分集选择。直链每5秒及暂停/关闭时保存时间；YouTube 只记录集数，时间由原平台管理。没有未经授权的动漫资源。
- 设置：连接状态与检测、个人 JSON 备份导出/恢复、云端管理员举报处理。

## 接通联网 AI

将 `.env.example` 复制成 `.env`，填入 `OPENAI_API_KEY`。按账号可用模型填写 `OPENAI_MODEL`，默认 `gpt-4.1-mini`。重启服务器。请求通过本机 Node 服务发送到 OpenAI Responses API，密钥不会返回网页。每次搜索会发送当前描述与本次会话此前的线索；API 可能收费。模型依知识识别，不会假装实时搜索过网络。

## 接通真实多人社区

1. 在 Supabase 新建你自己的项目。在 SQL Editor 执行 `schema.sql`。
2. 将项目 HTTPS URL 填入 `.env` 的 `SUPABASE_URL`，将 **anon 或 publishable 公开密钥** 填入 `SUPABASE_ANON_KEY`。绝不使用 service_role/secret key。
3. 启用邮箱密码登录。默认建议保留邮箱验证；注册后打开验证邮件，再返回本地页面登录。在 Supabase Auth URL 配置中将 `http://127.0.0.1:3210` 设为适当的 Site URL / Redirect URL。
4. 重启本地服务，在设置中“测试社区连接”。
5. 其他人使用相同前端与相同 Supabase 公开配置，也可以在自己的电脑本地启动后访问同一社区。当前服务只监听本机，不会自动生成别人可访问的公网网址。
6. 要处理举报，先注册管理员账号，再在 SQL Editor 按 `schema.sql` 末尾示例将它加入 admins 表。普通用户不能授予自己管理员权限。

云端数据库启用 RLS：普通用户只能创建自己的内容、编辑删除自己的帖子与回复；不能修改他人帖子或授予管理员；只有管理员可查看全部举报并处理。采纳的答案必须属于对应求助帖。报告数据保存在云端，界面刷新可获取更新，不包含即时推送。

**目前没有预置服务账号、密钥或实际云端项目。** 因此真实注册/社区和 AI 只有在完成上述配置后才能使用。默认仅显示明确标注的只读社区示例。云端权限策略已提供，但在你的真实项目中仍需用两个普通账号和管理员做集成验收。

## 数据在哪里

`data/personal.json` 保存搜索历史、收藏、手动追番、播放库和观看进度；采用临时文件写入再改名的方式保存。该目录必须有写权限。程序发现数据文件损坏会停止启动，不会默默覆盖。

这些个人记录属于 **这台电脑的本地庭院**，由本机访问者共享，不随社区账号切换。浏览器 localStorage 仅保存云端登录会话，密码不保存；清理浏览器缓存会退出登录，但不影响数据文件。帖子、评论、点赞、举报和账号在 Supabase；本地备份不包含它们。移动项目时一起保留 data 文件夹，并定期导出备份。

## 检查

执行 `npm test` 运行本机 HTTP 与重启持久化检查，测试使用独立临时项目，不改写你的数据。浏览器端请检查七个导航入口、追番编辑与备份恢复。

参考文档：[Supabase 登录](https://supabase.com/docs/reference/javascript/auth-signinwithpassword)、[行级权限](https://supabase.com/docs/guides/database/postgres/row-level-security)、[OpenAI Responses](https://developers.openai.com/api/reference/resources/responses/methods/create)。

# 心选购物

填写预算，逐件选择喜欢程度，比较三个购物方案。商品图片和评分保存在本机，无需联网使用。

## 下载

[下载 Windows x64 完整运行包](https://github.com/zhangxxx843-stack/mjmjmj/raw/refs/heads/main/packages/XinXuanShopping-v7-Windows-x64.zip)

请下载上面的运行包；GitHub 的“Download ZIP”是源码包，不能直接打开应用。当前为 v7 测试版，完整主流程尚待 Windows 实测验收。

## 打开应用

适用于 Windows x64。完整解压应用包，双击 `Start.cmd`；请保留同目录的 DLL 和 `assets` 文件夹。
首次打开会自动载入五件未评分的示例商品，预算由你填写。窗口较小时，可在右侧内容区域滚动；侧栏始终保留页面入口。

## 制订购物计划

1. 填写预算。预算和商品价格目前接受 1 到 1000 的整数。
2. 在清单中直接修改商品名称、价格；修改后保留原评分。删除商品需要确认。
3. 点击“继续评分”或侧栏“逐件评分”。每张卡片显示图片、名称、价格和五档喜欢程度；未选择时不能进入下一件。
4. 可以点击“上一件”修改选择。最后一件点击“查看三个推荐方案”。
5. 方案显示所选商品、总价和剩余预算，第一张标记“最佳方案”。每件商品最多选一次，不显示评分数字。

如果预算下不足三个不同的可行组合，只显示实际存在的组合；没有可购买商品时提示调整预算或清单。

## 保存与继续

有效修改会自动保存。数据和图片副本位于当前 Windows 账户的应用数据目录 `%LOCALAPPDATA%\XinXuanShopping`，移动程序或原图片不影响已保存的图片副本。
重新打开先显示恢复后的清单，再点击“继续评分”。已全部评分时，可直接查看方案或在方案页调整喜欢程度。

出现“尚未保存”时，当前内容仍保留，可以修正输入或重试保存。此时关闭窗口，可选择重试保存后退出、放弃并退出或取消退出。
若存档损坏，应用会提示恢复情况并保留原文件。需要备份数据时，请先关闭应用，再复制整个数据目录。

## 当前版本范围

本阶段支持内置商品的编辑、逐件评分、组合推荐和本地保存。CSV 校验模块已准备，但导入、补图和新增商品的界面入口尚未开放。

## 遇到问题

从 `Start.cmd` 启动后，运行记录保存在同目录的 `run-log.txt`。反馈时可附上该文件、提示文字和窗口截图。

# 第一版页面结构与设计草案

状态：界面设计草案；Ubuntu 试用界面已按桌面侧栏布局实现，Windows、Android、iOS 原生界面仍待适配。

## 产品约束

离线使用、人民币个人支出记账。无需登录或注册，打开应用直接进入明细。
记录每日消费，支持账单修改与删除、日期及月份查询、单日总结、月度统计、月度预算和本地保存。
大类与子类均可新增、重命名，自建大类下也能新增子类。
目标为 Windows、Android 和 iOS；Ubuntu 用于开发、检查和改善。

## 设计选择

本草案采用“明细、统计、预算、分类”四个固定入口，底部中间的大号“＋”为记账键。
手机端底栏顺序为“明细、统计、＋、预算、分类”，大号“＋”与页面导航在视觉上区分。
这样既能直接查看消费，又能随时进入预算和分类；无账号体系，因此不设置“我的”页。
曾考虑把预算与分类收进统一的管理页，但会增加常用功能的查找步骤。
此处的导航、配色与暂用名称“随手记”为本轮设计提案，可在看稿后调整。

## 页面与操作

| 页面 | 展示内容 | 主要操作 |
| --- | --- | --- |
| 明细（首页） | 选定日期或月份、支出合计、账单列表、单日总结、当月预算摘要 | 切换日/月、查看账单、记一笔 |
| 选择大类弹层 | 从底部弹出的支出大类列表 | 选择大类进入金额输入；关闭返回原页面 |
| 记一笔／编辑账单 | 已选大类、金额、日期、备注／小类说明（选填） | 保存、取消、重新选择大类；编辑时预填原值 |
| 账单详情 | 金额、分类路径、日期、备注 | 编辑、二次确认后删除 |
| 统计 | 按日或按月的支出合计、笔数与各大类金额、占比 | 切换统计时间范围 |
| 预算 | 指定月份预算、已用金额、剩余或超支金额、使用比例 | 设置或修改本月总预算 |
| 分类管理 | 大类列表、选中大类下的子类 | 新增大类、在选中大类下新增子类、重命名 |
| 分类命名面板 | 当前名称、名称输入框、重名提示 | 保存名称、取消 |

手机端四入口与大号“＋”位于底部，电脑端四入口位于左侧，并保留显眼的“＋”记账动作。
主页面标题区不再重复放置记账按钮。弹层选择大类后进入记账表单，返回时可重新选择大类。

## 核心流程

1. 点击底部“＋” → 弹出大类列表 → 选择大类 → 输入金额 → 可填写备注说明小类 → 确认日期 → 保存。
   例如选择“餐饮”，输入 18.00，备注“午餐 · 食堂盖饭”。记账表单不强制单独选择子分类。
2. 明细选择日期 → 查看当天账单与单日总结；切到整月查看当月列表。
3. 点击某笔账单 → 查看详情 → 编辑并保存，或确认删除。
4. 分类管理选择大类 → 新增子类；大类改名后关联账单同步显示新的大类名称。
5. 预算选择月份 → 填写总预算 → 保存；明细摘要同步更新。

## 视觉与尺寸

- 暂用名称：随手记。
- 浅色模式以米白背景、白色内容面和深绿色主操作为主；深色模式使用对应深色表面。
- 金额采用等宽数字；主要合计大字显示，账单金额右对齐并保留两位小数。
- 页面以留白、分隔线和少量必要的内容面区分层级。
- 支出用金额前的减号表达，超预算同时使用文字提示，不能只靠颜色。
- 手机宽度 320–430 像素采用单栏；桌面采用侧栏与主内容区，必要摘要可并排展示。
- 可点击区域至少约 44 像素高，表单输入字号不小于 16 像素。
- 可编辑内容使用明确标签，错误紧邻表单显示，成功操作有简短反馈。

## 状态与规则

- 无账单：显示所选时间尚无记录，并提供记账入口。
- 无预算：显示“尚未设置预算”，提供设置入口，不显示虚假的剩余额度。
- 超预算：显示超支金额，进度条视觉宽度最多 100%，文字仍显示实际比例。
- 金额必须大于零，最多两位小数；金额、大类和日期均为必填。
- 备注／小类说明为选填，未填写也能保存；没有子类的大类也可以直接记账。
- 表单保留“重新选择”大类的入口，切换大类时保留已填写的金额、日期与备注。
- 新增或重命名分类时拒绝空白名称及同层级重名，历史账单以稳定的大类标识关联。
- 备注是用户输入的自由文本，分类重命名不会自动改写原备注。
- 本轮不增加分类删除，避免产生历史记录归属不明的交互。
- 删除账单需要再次确认；取消编辑不改变原记录。
